# Seger Elo report — 2026-10

**Verdict: improving.** Absolute strength is up about +225 Elo against the last
report (~2285 → ~2513). The fixed-depth self-play against the pinned reference
reads *negative*, but that is expected and explained below: the reference
predates the move-ordering fix, and the current build deliberately trades tree
size for speed, which only pays off under a time control.

## Self-play vs the pinned reference

- Command: `python3 tools/selfplay.py --a build/seger --b /tmp/seger_ref_bin --games 60 --depth 5 --parallel 4`
- Reference sha (`reports/elo/baseline.sha`): `e58ee82621563a26ad2edd7138d91d6fc03e71f1`
- Current `HEAD`: `c3abde0` (29 commits ahead of the previous report, 30 ahead of the reference).
- Result: A (HEAD) 8 W, 26 D, 26 L — **A score 21.0/60 = 0.350**, Elo delta **-107.5** (+/- 92 at 95%).

The roles were then swapped (`--a /tmp/seger_ref_bin --b build/seger`) to cancel
the harness's side-A bias: the reference scored 0.650 (26 W, 26 D, 8 L), i.e.
**+107.5** for the reference. Both directions agree, so the negative reading is
real at fixed depth 5 — it is not the side bias.

Why a stronger engine reads negative here: the reference is the *pre move-ordering
fix* build. At depth 9 from startpos it searches **140,502,299 nodes**; the current
build searches **849,506** (165x fewer) at ~1.53 Mnps. The current build leans on
late-move reductions, futility and reverse-futility pruning, all of which cut the
tree aggressively. At a shallow *fixed depth* that trade loses (it searches less
thoroughly); under a *time control* it wins, because the extra speed converts to
depth. AGENTS.md records exactly this pattern: the move-ordering fix alone was
+114 Elo at 100 ms/move, and LMR +172 Elo, both under time control.

## Honest note

The fixed-depth self-play delta (-107.5 Elo) is larger than its own confidence
interval (+/- 92), so it is a *real* fixed-depth regression, not noise — but it is
the expected cost of the pruning that buys depth under a time control. The
absolute Stockfish anchors, which use a time control, show the opposite and much
larger effect (+225 Elo). The absolute number is the one that reflects playing
strength; the fixed-depth number measures tree size, not strength. Each anchor's
interval is over 130 Elo wide at 30 games, so ~2513 is a ballpark, not a precise
rating.
